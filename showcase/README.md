# Small tools. Better days.

An independent, Apple-inspired editorial showcase of john3smith's public GitHub projects. Korean copy, original CSS/SVG product illustrations, floating devices, scroll reveals, motion controls and responsive project details.

**[Download the standalone HTML from Releases](https://github.com/john3smith/john3smith/releases/tag/showcase-v1.0.0)**

Save `John3smith-Public-Projects.html` and open it in a modern browser. GitHub's file view displays source, so download the HTML to see the complete experience. No GitHub Pages setting is required or changed.

## Design and accessibility

- One UTF-8 HTML file with inline CSS, JavaScript and SVG. No external fonts, images, scripts, tracking, API calls or runtime dependencies.
- Animated device studies, project illustrations, scroll reveals and progress indicator; offscreen and background-tab animation suspension.
- Project filters, Korean feature search, empty state, native modal dialogs, keyboard focus, Escape dismissal and sticky close controls.
- Respects `prefers-reduced-motion` and includes a persistent manual motion switch. Responsive layouts include 1440px, 390px and 320px widths.
- Static project cards remain readable if JavaScript is unavailable. Print styles remove decorative motion and show the full collection.

Product illustrations are original visual interpretations of documented features, not actual app screenshots. This showcase is independent and is not affiliated with Apple.
